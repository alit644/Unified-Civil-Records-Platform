## 📖 نظرة عامة

**النظام الرقمي الموحد للسجل المدني** هو تطبيق ويب مؤسسي يُمكّن موظفي السجل المدني من إدارة كافة العمليات الإدارية رقمياً وبشكل آمن. يتبنى النظام بنية **متعددة الأدوار** (RBAC) لضمان أن كل مستخدم يرى ويتفاعل فقط مع الصلاحيات الممنوحة له.

## ✨ الميزات الرئيسية

### 🏠 لوحة التحكم الرئيسية (Dashboard)

- **إحصاءات فورية:** عرض بطاقات المقاييس الحية لإجمالي المواطنين المسجلين، الواقعات المسجلة اليوم، الوثائق الصادرة، والمعاملات المعلقة.
- **أحدث الواقعات:** جدول تفاعلي يعرض آخر الواقعات المدنية المسجلة مع حالتها ونوعها والموظف المسؤول.
- **الإجراءات السريعة:** اختصارات مباشرة للانتقال إلى تسجيل واقعة، إضافة مواطن، أو إصدار وثيقة.
- **ترحيب شخصي:** يعرض اسم الموظف المسجل والتاريخ الحالي.

### 👥 إدارة المواطنين (Citizens Management)

- **سجل مواطن شامل:** تخزين كامل لبيانات المواطن تشمل: الاسم الرباعي، الرقم الوطني الفريد، مكان وتاريخ الولادة، رقم وأمانة القيد، رقم دفتر العائلة، الديانة، والعنوان الحالي.
- **توليد الرقم الوطني تلقائياً:** خوارزمية ذكية تولّد أرقاماً وطنية فريدة وغير مكررة مبنية على سنة الميلاد ورمز المحافظة.
- **الشجرة العائلية (Family Tree):** ربط برمجي للمواطنين بآبائهم وأمهاتهم، مما يبني شجرة عائلية كاملة داخل قاعدة البيانات.
- **بحث متقدم متعدد الأبعاد:** البحث بالاسم الكامل، الرقم الوطني، أو رقم دفتر العائلة — مع دعم الـ Debouncing لتجنب الطلبات المتكررة.
- **فلترة ذكية:** فلترة النتائج بـ الجنس (ذكر/أنثى)، حالة السجل (نشط، معلق، متوفى، غير نشط)، مع زر إعادة تعيين سريع.
- **تصفح بالصفحات:** نظام Pagination كامل مع عرض نطاق النتائج من أصل الإجمالي.
- **صفحة تفاصيل المواطن:** عرض شامل يتضمن أقساماً لـ بيانات شخصية، حالة مدنية، بيانات الولادة، وتفاصيل القيد.
- **تعديل البيانات:** Drawer لتعديل بيانات المواطن مع تتبع التغييرات في سجل التدقيق.
- **تصدير Excel:** تصدير نتائج البحث الحالية إلى ملف XLSX بضغطة واحدة.

### 📋 الواقعات المدنية (Civil Events)

يدعم النظام تسجيل **أربعة أنواع** من الواقعات المدنية:

| الواقعة | التفاصيل |
|---------|----------|
| **🍼 تسجيل الولادة** | ربط المولود بوالديه (التحقق من الرقم الوطني لكل منهما)، تسجيل مكان وتاريخ الولادة، رقم وثيقة المستشفى |
| **💍 تسجيل الزواج** | التحقق من الرقم الوطني للزوج والزوجة، تاريخ ومكان عقد القران، رقم وثيقة المحكمة |
| **⚖️ تسجيل الطلاق** | التحقق من الرقم الوطني للزوجين، تاريخ ومكان الطلاق، رقم وثيقة المحكمة |
| **🕊️ تسجيل الوفاة** | التحقق من الرقم الوطني للمتوفى، تاريخ ومكان الوفاة، رقم وثيقة المشفى |

**ميزات إضافية للواقعات:**
- **نظام الاعتماد (Approval Workflow):** كل واقعة تُسجَّل بحالة `PENDING` وتنتظر موافقة المدير (`ADMIN`) قبل الاعتماد النهائي.
- **التحقق من الهوية:** قبل تسجيل أي واقعة، يتحقق النظام من وجود المواطن المعني عبر الرقم الوطني.
- **فلترة الواقعات:** تصفية حسب نوع الواقعة (ولادة، زواج، طلاق، وفاة).
- **صفحة تفاصيل الواقعة:** عرض كامل للواقعة مع بيانات الأطراف، التواريخ، والوثائق المرفقة.

### 📄 إصدار الوثائق الرسمية (Document Issuance)

- **إصدار سريع بنقرة واحدة:** اختيار المواطن عبر البحث الفوري، تحديد نوع الوثيقة، ثم إصدار الوثيقة مباشرةً.
- **وثيقة PDF احترافية:** توليد تلقائي لوثيقة PDF رسمية تحتوي على بيانات المواطن، رقم الأرشفة الفريد، وبيانات الموظف المصدِر.
- **معاينة PDF داخل التطبيق:** عرض الوثيقة في Modal قبل الطباعة أو الحفظ.
- **قائمة الوثائق الصادرة:** جدول يعرض أحدث الوثائق الصادرة مع نوعها، رقم أرشفتها، الموظف، والوقت.
- **رقم أرشفة فريد:** كل وثيقة تحصل تلقائياً على رقم أرشفة فريد للتتبع.
- **رمز QR:** وثيقة بيان القيد تتضمن رمز QR يحتوي على الرقم الوطني للمواطن.

### 👔 إدارة الموظفين (Employees Management)

> متاحة فقط لـ **ADMIN**

- **عرض كامل للموظفين:** جدول يعرض الاسم، اسم المستخدم، الدور، الحالة، عدد المعاملات والوثائق لكل موظف.
- **إضافة موظف جديد:** Drawer مع نموذج تسجيل يتضمن التحقق من صحة البيانات.
- **تعديل دور الموظف:** تغيير الدور بين (ADMIN, OFFICER, AUDITOR) مع تأثير فوري على الصلاحيات.
- **تفعيل / تعطيل الحساب:** تبديل حالة الموظف مع حماية المديرين من التعطيل.
- **تصفح بالصفحات:** Pagination لقوائم الموظفين الطويلة.

### 🔍 البحث العالمي (Global Search)

- **شريط بحث في الهيدر:** متاح من أي صفحة في التطبيق.
- **نتائج فورية مع Debouncing:** البحث يبدأ بعد إدخال حرفين فأكثر مع تأخير 300ms لتقليل الطلبات.
- **التنقل للملف الشخصي:** النقر على أي نتيجة ينقلك مباشرةً لصفحة تفاصيل المواطن.
- **مؤشر التحميل:** Spinner أثناء جلب النتائج من الخادم.

### 🔐 سجل التدقيق الكامل (Full Audit Trail)

> متاح لـ **ADMIN** و **AUDITOR**

- **توثيق كامل لكل عملية:** كل إضافة أو تعديل يُسجَّل مع اسم الموظف، التاريخ والوقت بالثانية، الجدول المتأثر، ومعرف السجل.
- **عرض التغييرات (Diff):** يعرض البيانات القديمة (مشطوبة) والجديدة (مظللة بالأخضر) لكل تعديل.
- **فلترة سجلات التدقيق:** تصفية حسب الموظف، نوع الإجراء، أو الفترة الزمنية.
- **إجمالي السجلات:** عداد يعرض العدد الكلي لسجلات التدقيق.
- **Pagination:** تصفح سجلات التدقيق بصفحات مع تحديد إجمالي الصفحات.

### 🗄️ الأرشيف الرقمي (Digital Archive)

صفحة "قريباً" مصممة باحترافية تعرض للمستخدمين الميزات القادمة، تتضمن:
- البحث الذكي برقم الأرشيف أو الرقم الوطني.
- تحميل الوثائق بصيغة PDF عالية الجودة.
- أرشفة إلكترونية فورية للسجلات الجديدة.
- سجل تدقيق أمني لمتابعة حركات الوصول.

## 🗄️ نماذج قاعدة البيانات

```
Employee      → الموظفون (مع الأدوار والجلسات)
Citizen       → المواطنون (مع الشجرة العائلية)
CivilEvent    → الواقعات المدنية (ولادة/زواج/طلاق/وفاة)
Document      → الوثائق الرسمية الصادرة
AuditLog      → سجلات التدقيق الكاملة
Session       → جلسات المستخدمين (Better Auth)
Account       → حسابات المصادقة (Better Auth)
```

### خطوات التثبيت

**1. استنساخ المشروع**
```bash
git clone https://github.com/alit644/Unified-Civil-Records-Platform.git
cd Unified-Civil-Records-Platform
```

**2. تثبيت المكتبات**
```bash
npm install
```

**3. إعداد متغيرات البيئة**

أنشئ ملف `.env` في جذر المشروع:
```env
DATABASE_URL="postgresql://user:password@localhost:5432/civil_records"
BETTER_AUTH_SECRET="your_secret_key_here"
BETTER_AUTH_URL="http://localhost:3000"
```

**4. توليد Prisma Client وتهيئة قاعدة البيانات**
```bash
npx prisma generate
npx prisma db push
```

**5. (اختياري) تشغيل البيانات الأولية**
```bash
npx prisma db seed
```

**6. تشغيل بيئة التطوير**
```bash
npm run dev
```

افتح المتصفح على `http://localhost:3000`

## 🌐 النشر على Vercel

| المتغير | الوصف |
|---------|-------|
| `DATABASE_URL` | رابط قاعدة PostgreSQL (يُنصح بـ Neon أو Supabase) |
